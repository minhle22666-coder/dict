Sau khi tải seed.json

  1. Thay file seed.json mẫu trong repo bằng file vừa tải (Add file → Upload, commit đè).
  2. Mở sw.js, tăng số ở dòng const CACHE = 'smartdict-vN' lên 1 (vd v4 → v5) rồi commit (để iPhone lấy bản mới).
  3. Trên iPhone: xoá icon app cũ, mở lại link bằng Safari → Add to Home Screen. Xong — 5000 từ nằm sẵn, offline hoàn toàn.
