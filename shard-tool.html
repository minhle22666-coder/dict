Chia shard từ điển Focci

Gộp mọi file seed JSON đang có, loại trùng, chia thành nhiều shard nhỏ và sinh dict-manifest.json. Đây là bước tạo ra nguồn dữ liệu duy nhất có version cho app.

1 · Chọn các file seed JSON

Nhận cả mảng bản ghi đầy đủ ([{word, data}]) và mảng data thuần ([{word, senses…}]) — kiểu nào cũng đọc được.

2 · Cấu hình

2.000 từ/shard là mức cân bằng tốt: đủ nhỏ để một shard lỗi không mất nhiều, đủ lớn để không tạo hàng trăm request.

3 · Tạo file

Chờ chọn file…

4 · Upload lên repo

Tải hết các file ở trên rồi upload vào repo dict (Add file → Upload files → commit). Cần đủ: dict-manifest.json, tất cả dict-XXX.json, và words.txt (danh sách toàn bộ từ, để đối chiếu về sau). Trong app: Settings → Dictionary Data → Đồng bộ từ repo.
